# FastAPI Authentication Server

Учебный проект, демонстрирующий реализацию аутентификации пользователей на **FastAPI** с использованием подписанных cookies.

В проекте реализована страница входа, проверка пароля (с солью), хранение пользователей в JSON-файле и защита cookies с помощью HMAC-подписи.

---

## 📌 Возможности

- Страница входа с формой (HTML + CSS + JavaScript);
- Проверка логина и пароля (пароль хранится в виде SHA-256 хеша с солью);
- Подписанные cookies (данные пользователя подписываются HMAC-SHA256);
- Безопасное удаление cookies при невалидной подписи;
- Отображение приветствия и баланса пользователя после успешного входа;
- Простое хранение пользователей в JSON-файле.

# Структура проекта

- **`server.py`** – основной файл приложения FastAPI (все маршруты и логика).
- **`add_user.py`** – вспомогательный скрипт для интерактивного добавления пользователей в `users.json`.
- **`templates/`** – папка с HTML-шаблонами:
  - `login.html` – страница входа.
- **`pip_requirements.txt`** – список зависимостей.
- **`.env`** – файл с секретными ключами (создаётся самостоятельно, **не хранится в репозитории**).
- **`users.json`** – база данных пользователей в формате JSON (создаётся автоматически или вручную, **не хранится в репозитории**).
- **`.gitignore`** – исключает из репозитория `.env`, `users.json`, виртуальное окружение и временные файлы.
- **`README.md`** – данный файл с документацией.

---

## 📄 Описание файлов

| Файл | Назначение |
|------|------------|
| **`server.py`** | **Основной файл** – содержит все маршруты FastAPI: главную страницу (`/`), обработку логина (`/login`), функции подписи данных, проверки пароля, валидации cookies. |

```bash
cd basic_FastAPI_server
```

### Создать виртуальное окружение (рекомендуется):

```bash
pip install -r pip_requirements.txt
```

## Настройка проекта

### Создание файла `.env`

В корневой папке создайте файл `.env` и добавьте в него две переменные:

```env
SECRET_KEY=сгенерируйте_случайную_строку
PASSWORD_SALT=сгенерируйте_другую_случайную_строку
```

### Как сгенерировать случайные строки

Выполните дважды в терминале:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Скопируйте полученные строки – одну для `SECRET_KEY`, другую для `PASSWORD_SALT`.

Пример содержимого `.env`:

```env
SECRET_KEY=9f86d081884c7d659a9fe9650e6d6e1b9c8b3e2f7a4c6d8e0f1a2b3c4d5e6f7a
PASSWORD_SALT=a1b2c3d4e5f67890abcdef1234567890abcdef1234567890abcdef12345678
```

> [!IMPORTANT]
> Не используйте эти примеры в продакшене – генерируйте свои уникальные ключи!

## Добавление пользователя в `users.json`

Вместо ручного вычисления хешей используйте вспомогательный скрипт `add_user.py`.

Запустите его в терминале:

```bash
python add_user.py
```

Следуйте инструкциям:

- введите логин (`username`);
- отображаемое имя;
- пароль (дважды для подтверждения);
- баланс (число, можно оставить `0`).

Скрипт сам создаст `users.json` (если его нет) и добавит пользователя с правильно вычисленным хешем пароля.

Повторите запуск для добавления нескольких пользователей.

## Запуск проекта

После настройки запустите сервер:

```bash
uvicorn server:app --reload
```

Сервер будет доступен по адресу:

http://127.0.0.1:8000

## Использование

1. Откройте страницу в браузере.
2. Введите логин и пароль одного из добавленных пользователей.
3. При успехе страница изменит цвет на зелёный и покажет приветствие с балансом.
4. При ошибке – появится сообщение **"Ты кто такой?!"**.

---

## Примечания по безопасности

- Файлы `.env` и `users.json` никогда не должны попадать в репозиторий (убедитесь, что они добавлены в `.gitignore`).
- Для продакшена используйте реальную базу данных (например, PostgreSQL) вместо JSON-файла и обязательно применяйте HTTPS.
- Пароли хранятся в виде хешей с солью, что защищает их в случае утечки `users.json`.
