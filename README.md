# FastAPI Authentication Server

Учебный проект, демонстрирующий реализацию аутентификации пользователей на **FastAPI** с использованием подписанных cookies.

В проекте реализована страница входа, проверка пароля (с солью), хранение пользователей в JSON-файле и защита cookies с помощью HMAC-подписи.

> [!IMPORTANT]
> Проект разработан с использованием **Python 3.10+** и **FastAPI 0.136.1**.
>
> Все зависимости перечислены в `pip_requirements.txt`.

---

## 📌 Возможности

- Страница входа с формой (HTML + CSS + JavaScript);
- Проверка логина и пароля (пароль хранится в виде SHA-256 хеша с солью);
- Подписанные cookies (данные пользователя подписываются HMAC-SHA256);
- Безопасное удаление cookies при невалидной подписи;
- Отображение приветствия и баланса пользователя после успешного входа;
- Простое хранение пользователей в JSON-файле.

# Настройка проекта (создание `.env` и `users.json`)

Два важных файла — `.env` и `users.json` — **не включены** в репозиторий по соображениям безопасности. Вам необходимо создать их вручную.

---

## Создание файла `.env`

В корневой папке проекта создайте файл `.env` и добавьте в него две переменные:

```env
SECRET_KEY=сгенерируйте_случайную_строку
PASSWORD_SALT=сгенерируйте_другую_случайную_строку
```

**Как сгенерировать случайные строки**  
Дважды выполните в терминале команду:

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

Скопируйте полученные строки и вставьте их в `.env` (одна для `SECRET_KEY`, другая для `PASSWORD_SALT`).

Пример содержимого `.env`:

```env
SECRET_KEY=9f86d081884c7d659a9fe9650e6d6e1b9c8b3e2f7a4c6d8e0f1a2b3c4d5e6f7a
PASSWORD_SALT=a1b2c3d4e5f67890abcdef1234567890abcdef1234567890abcdef12345678
```

> **Важно:** Не используйте примеры в продакшене. Генерируйте свои уникальные ключи.

---

## Создание файла `users.json`

В той же папке создайте файл `users.json`. Это будет база данных пользователей в формате JSON.

Структура файла:

```json
{
  "логин": {
    "name": "Отображаемое имя",
    "password": "хеш_пароля_с_солью",
    "balance": 1000
  }
}
```

- **`логин`** – строка, которую пользователь вводит в поле `username`.
- **`name`** – имя, которое будет показано после входа.
- **`password`** – хеш пароля, вычисленный по формуле:  
  `hashlib.sha256((пароль + PASSWORD_SALT).encode()).hexdigest().lower()`
- **`balance`** – число (например, начальный баланс).

### Как вычислить хеш пароля

Воспользуйтесь Python-скриптом (замените `ваша_соль` и `мой_пароль` на свои значения):

```python
import hashlib

PASSWORD_SALT = "ваша_соль_из_env"  # вставьте значение из .env
password = "мой_пароль"

hash_value = hashlib.sha256((password + PASSWORD_SALT).encode()).hexdigest().lower()
print(hash_value)
```

Скопируйте полученный хеш и вставьте в поле `"password"` для нужного пользователя.

**Пример готового `users.json`** (для пользователя `admin` с паролем `qwerty`):

```json
{
  "admin": {
    "name": "Администратор",
    "password": "ваш_посчитанный_хеш",
    "balance": 5000
  }
}
```

Можно добавить несколько пользователей, каждый с уникальным логином.

# Запуск проекта

После выполнения всех предыдущих шагов запустите сервер командой:

```bash
uvicorn server:app --reload
```

Флаг `--reload` автоматически перезагружает сервер при изменениях кода – удобно для разработки.

Сервер запустится по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000).

Откройте этот URL в браузере – вы увидите страницу входа.

# Использование

1. Введите логин и пароль, соответствующие данным в `users.json`.
2. Нажмите кнопку **Войти**.
3. При успешном входе страница изменит цвет на зелёный и покажет приветствие с балансом.
4. При неудаче – отобразится сообщение об ошибке.

После успешного входа в браузере будет установлена подписанная cookie `username`, которая позволяет серверу идентифицировать пользователя при последующих запросах.

# Примечания по безопасности

- Файлы `.env` и `users.json` **никогда не должны** попадать в репозиторий – они уже добавлены в `.gitignore`.
- Для продакшена рекомендуется использовать реальную базу данных (например, PostgreSQL) вместо JSON-файла, а также применять HTTPS.
- Пароли хранятся в виде хешей с солью, что защищает их в случае утечки `users.json`.
